# Architecture

Agent Kit is not a single framework — it is **42 independent packages layered by capability**. Each package stands alone, and they compose freely into a complete agent infrastructure.

## Core design principles

### 1. Zero runtime dependencies

Every package's `package.json` has zero runtime dependencies — only Node.js built-in modules (`node:crypto`, `node:vm`, `node:fs`, etc.) are used. This means:

- Fast installs, tiny footprint
- No supply-chain risk (zero npm dependency-injection attack surface)
- Coexists with any framework (LangChain, Mastra, your own framework...)

### 2. Factory functions first

Public constructors are consistently `createX()` factory functions instead of `new X()`:

```ts
import { createEventBus } from "@fengrru/event-bus"

const bus = createEventBus({ maxQueueSize: 1000 })
```

### 3. Dependency injection

Packages that need external resources (file systems, LLMs, parsers) accept them via injected interfaces, making them easy to test and swap:

```ts
import { createCodeGraphBuilder } from "@fengrru/codegraph"

const builder = createCodeGraphBuilder({
  fs: myFileSystem, // inject a custom implementation
  config: { maxDepth: 3 },
})
```

### 4. Independent evolution

All 42 packages are versioned and released independently (driven by Changesets), never blocking each other. Internal collaboration dependencies use `workspace:*` and are replaced with concrete versions at publish time.
